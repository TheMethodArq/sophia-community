# Sophia v2 — Data Models, Artifacts & Templates

## Overview

This document defines the data structures, artifact formats, and templates used throughout the Sophia v2 workflow. All schemas are validated with Zod at runtime.

---

## Core Schemas

### Requirements Schema

The primary input artifact. Written by the user (Phase 1 MVP) or generated from chat (Phase 3).

```yaml
# requirements.yaml
version: "2.0"
locked: true                     # false during drafting, true after lock
locked_at: "2024-01-15T10:00:00Z"
lock_hash: "sha256:abc123..."    # Hash of content at lock time

project:
  name: string                   # kebab-case, no spaces
  description: string            # 1-2 sentence summary
  type: web-app | api | cli | mobile | full-stack | library

tech_stack:
  language: typescript | javascript | python | go | rust
  framework: nextjs | react | vue | svelte | fastapi | express | gin | none
  database: postgresql | mysql | sqlite | mongodb | none
  orm: prisma | drizzle | typeorm | sqlalchemy | none
  ui: shadcn | radix | material | chakra | custom | none
  styling: tailwind | css-modules | styled-components | none
  testing: vitest | jest | pytest | go-test
  e2e: playwright | cypress | none
  auth: nextauth | clerk | custom | none
  deployment: vercel | aws | gcp | docker | none

requirements:
  product: string[]              # Feature descriptions
  technical: string[]            # Technical constraints
  testing: string[]              # Testing requirements
  architecture: string[]         # Architecture decisions

personas:
  - name: string
    type: frontend | backend | both
    description: string
    journeys:
      - string                   # Each journey is a narrative description

quality:
  lighthouse_target: number      # 0-100, default 90
  accessibility: WCAG-A | WCAG-AA | WCAG-AAA
  design_system: string          # Name of design system to use
  test_coverage_target: number   # 0-100, default 80
```

### Zod Validation

```typescript
import { z } from 'zod';

const RequirementsSchema = z.object({
  version: z.literal('2.0'),
  locked: z.boolean(),
  locked_at: z.string().datetime().optional(),
  lock_hash: z.string().optional(),

  project: z.object({
    name: z.string().regex(/^[a-z0-9-]+$/),
    description: z.string().min(10).max(500),
    type: z.enum(['web-app', 'api', 'cli', 'mobile', 'full-stack', 'library']),
  }),

  tech_stack: z.object({
    language: z.enum(['typescript', 'javascript', 'python', 'go', 'rust']),
    framework: z.enum(['nextjs', 'react', 'vue', 'svelte', 'fastapi', 'express', 'gin', 'none']),
    database: z.enum(['postgresql', 'mysql', 'sqlite', 'mongodb', 'none']),
    orm: z.enum(['prisma', 'drizzle', 'typeorm', 'sqlalchemy', 'none']),
    ui: z.enum(['shadcn', 'radix', 'material', 'chakra', 'custom', 'none']),
    styling: z.enum(['tailwind', 'css-modules', 'styled-components', 'none']),
    testing: z.enum(['vitest', 'jest', 'pytest', 'go-test']),
    e2e: z.enum(['playwright', 'cypress', 'none']),
    auth: z.enum(['nextauth', 'clerk', 'custom', 'none']),
    deployment: z.enum(['vercel', 'aws', 'gcp', 'docker', 'none']),
  }),

  requirements: z.object({
    product: z.array(z.string().min(10)).min(1),
    technical: z.array(z.string()).default([]),
    testing: z.array(z.string()).default([]),
    architecture: z.array(z.string()).default([]),
  }),

  personas: z.array(z.object({
    name: z.string(),
    type: z.enum(['frontend', 'backend', 'both']),
    description: z.string(),
    journeys: z.array(z.string()).min(1),
  })).min(1),

  quality: z.object({
    lighthouse_target: z.number().min(0).max(100).default(90),
    accessibility: z.enum(['WCAG-A', 'WCAG-AA', 'WCAG-AAA']).default('WCAG-AA'),
    design_system: z.string().default('shadcn'),
    test_coverage_target: z.number().min(0).max(100).default(80),
  }).default({}),
});
```

### Sprint Plan Schema

Generated by the Planner agent. Defines the implementation plan.

```yaml
# docs/plans/IMPLEMENTATION_PLAN.yaml
version: "2.0"
project: string
created_at: string
approved: boolean
approved_at: string | null

sprints:
  - id: sprint-01
    name: string
    goal: string                 # 1-sentence sprint goal
    acceptance_criteria:
      - string
    estimated_tokens: number
    epics:
      - id: epic-01
        name: string
        description: string
        tasks:
          - id: task-001
            name: string
            type: scaffold | code | test | config | docs
            description: string
            files:
              create: string[]   # New files this task creates
              modify: string[]   # Existing files this task modifies
              read: string[]     # Files needed for context (read-only)
            test_spec: string    # TDD test description
            depends_on: string[] # Task IDs this depends on
            model: opus | sonnet | haiku
            estimated_tokens: number

token_budget:
  planning: number
  build_total: number
  per_sprint:
    sprint-01: number
    sprint-02: number
  testing: number
  delivery: number
  total: number
  estimated_cost_usd: number

ci_cd:
  provider: github_actions | google_cloud_build
  triggers:
    on_commit: boolean
    on_sprint_tag: boolean
  checks: string[]
```

### Task Result Schema

Returned by agents after task execution.

```yaml
task_result:
  task_id: string
  agent: string
  model: string
  success: boolean
  timestamp: string

  files:
    created: string[]
    modified: string[]
    deleted: string[]

  tests:
    run: number
    passed: number
    failed: number
    skipped: number

  tokens:
    input: number
    output: number
    total: number

  decisions:
    - description: string
      choice: string
      reason: string
      alternatives: string[]

  errors: string[]               # Empty if success

  needs_context: string[] | null # Files/info needed but not provided
```

### Audit Entry Schema

Every governance event produces an audit entry.

```yaml
audit_entry:
  id: string                     # UUID
  timestamp: string              # ISO-8601
  project: string
  phase: brainstorm | lock | plan | build | test | deliver
  sprint: string | null
  task: string | null
  type: gate_evaluation | policy_check | approval_decision | agent_execution | escalation | error | state_change
  agent: string | null
  model: string | null
  action: string                 # Human-readable description
  result: pass | fail | warn | approved | rejected | pending | skipped

  context:
    description: string
    artifacts: string[]          # File paths involved
    token_cost: number
    duration_ms: number

  human_input:
    required: boolean
    provided: boolean
    decision: string | null
    notes: string | null
```

### Token Usage Schema

Real-time tracking of token consumption.

```yaml
# .sophia/token-usage.yaml
project: string
last_updated: string

totals:
  budget: number
  actual: number
  estimated_cost_usd: number
  actual_cost_usd: number

by_phase:
  brainstorm: { budget: number, actual: number }
  planning: { budget: number, actual: number }
  build: { budget: number, actual: number }
  testing: { budget: number, actual: number }
  delivery: { budget: number, actual: number }

by_sprint:
  sprint-01: { budget: number, actual: number }
  sprint-02: { budget: number, actual: number }

by_model:
  opus: { calls: number, input_tokens: number, output_tokens: number }
  sonnet: { calls: number, input_tokens: number, output_tokens: number }
  haiku: { calls: number, input_tokens: number, output_tokens: number }

by_agent:
  planner: { calls: number, total_tokens: number }
  builder: { calls: number, total_tokens: number }
  reviewer: { calls: number, total_tokens: number }
  tester: { calls: number, total_tokens: number }
  scaffolder: { calls: number, total_tokens: number }
  documenter: { calls: number, total_tokens: number }
```

### File Summary Schema

Cached per file for lightweight context loading.

```yaml
# .sophia/summaries/{file-path}.yaml
path: string
type: component | hook | utility | api-route | model | config | test | page | layout
language: typescript | javascript | python | go | rust

exports:
  - name: string
    type: function | class | component | hook | constant | type | interface
    signature: string            # Function/method signature
    description: string | null   # JSDoc/docstring if present

imports:
  - from: string                 # Module path
    names: string[]              # Named imports

lines: number
last_modified: string            # ISO-8601
summary_generated: string        # ISO-8601
```

## Change Request Schema

```yaml
change_request:
  id: string                     # CR-001, CR-002, etc.
  created_at: string
  status: pending | approved | rejected | implemented

  original_requirement: string   # Reference to locked requirement
  requested_change: string       # Description of change
  reason: string                 # Why the change is needed

  impact_analysis:
    sprints_affected: string[]
    tasks_affected: string[]
    estimated_token_cost: number
    estimated_time_impact: string

  approval:
    approved_by: string | null
    approved_at: string | null
    notes: string | null

  new_version: string | null     # requirements-v2.yaml if approved
```
